# Результат исправлений

Дата: 1 октября 2026 года. Исходный аудит: [project-audit.md](project-audit.md).

## Что изменено

- Общий словарь объединяет исходную и AI-лексику по устойчивым идентификаторам. Формы существительных, глаголов и конструкции показываются в занятиях и повторении.
- Завершение требует непустой проверенной попытки каждого упражнения и письменной попытки от 20 слов. Ошибки допустимы; завершение не объявляется освоением навыка. Повторный клик не создает новое занятие.
- Учебные дни текущей недели, разные выполненные занятия и серия считаются отдельно. Пропущенный будний день сбрасывает текущую серию; выходные необязательны. Ложный общий процент курса убран.
- Добавлены начальная проверка, девять наблюдаемых навыков и предпосылки для выбора следующего занятия. Подсказки и первые попытки учитываются отдельно. Подтверждение спустя время требует разных заданий и задержки, а не повторного нажатия на правильный ответ.
- Goethe B1 и telc B1 сохраняются в профиле. AI получает цель, темы, результаты и ошибки; создаются вопросы на понимание текста. Каждое пятое занятие получает учебный таймер, который сохраняется при запросе нового AI-варианта.
- Перевод, отличающийся от образца, требует проверки смысла и не объявляется автоматически ошибкой. Заглавные буквы проверяются отдельно. Письмо получает пять критериев вместо необъяснимого общего балла; стилистические предложения не попадают в журнал ошибок как доказанные ошибки.
- Исправленный образец письма скрыт до запроса. Ученик может изменить текст и проверить снова; версии с обратной связью сохраняются. Ошибки назначаются на самостоятельное исправление, затем на новую ситуацию через три дня.
- Повторение требует воспроизведения перед образцом, чередует направления, использует короткие шаги обучения и ограничивает новые слова пятью в день. Большой долг повторения блокирует новые карточки.
- Занятия, проверки, подсказки, исправление ошибок и текст диалога сохраняются. Переход между страницами не превращает попытку с подсказкой в самостоятельную. Асинхронные результаты обновляют актуальное состояние; поздний разбор письма не отменяет завершение и не переключает новое занятие на старое.
- Прежний браузерный голосовой ввод освобождается при выходе, не дублирует накопленные финальные фразы. Диалог сохраняет историю, позволяет ответить на уточняющий вопрос и пополняет общий журнал ошибок. Его балл относится к тексту.
- Формат данных v2 мигрирует v1. Импорт проверяет структуру и связи до изменения прогресса. Поврежденное хранилище сохраняется для восстановления; ошибка квоты оставляет работу в памяти и позволяет повторить сохранение или экспортировать JSON. Изменения синхронизируются между вкладками.
- AI-клиент создается после проверки конфигурации. Все маршруты возвращают безопасные JSON-ошибки, ограничивают размер и нагрузку, проверяют ответы модели. Production AI требует защиты паролем; HTTP Basic поддерживает UTF-8. Совместимые зависимости обновлены.

## Проверка

26 автоматических тестов проверяют основные переходы состояния, миграцию, поврежденные данные, синхронизацию вкладок, интервалы, подсказки, контрольные занятия и API с подставным провайдером.

В работающем интерфейсе проверены блокировка пустого завершения, сохранение ответа и письма после навигации и перезагрузки, выполнение начальной проверки, счетчики, повторение слова, сохранение текстового диалога, отказ от поврежденного импорта и создание следующего занятия. Проверка выполняется в отдельном локальном адресе с тестовым прогрессом.

Также проверено, что ответ и отметка о подсказке в исправлении ошибки сохраняются после перезагрузки: правильный ответ после подсказки не засчитывается как самостоятельный успех. Ошибок в консоли браузера не обнаружено. [Снимок итогового интерфейса](screenshots/dashboard.png).

Команды окончательной проверки: `npm test`, `npm run lint`, `npm run typecheck`, `npm run build`. Проверка установленных зависимостей: `npm audit`.

Все 26 тестов, ESLint, TypeScript и production-сборка завершились успешно. `npm audit` сообщает 0 известных уязвимостей в установленном дереве зависимостей.

## Границы результата

Аудирование и запись аудио не добавлены по запросу пользователя. Полная оценка говорения и полный пробный экзамен требуют этих отдельных навыков. Учебный таймер и рубрика не заменяют официальный экзамен и его оценивание.

Встроенный банк заданий небольшой; AI расширяет разнообразие под выбранную цель. Выбранная сложность материалов не является измеренным общим уровнем. Интервалы и правила подтверждения являются прозрачными настройками методики, но эффективность для конкретного ученика нужно проверять по результатам новых задач.

Реальные запросы OpenAI и педагогическое качество живых ответов модели в этой проверке не оценивались. Тесты используют подставного провайдера. Лимит API действует на один процесс; несколько экземпляров требуют общего лимитера. Данные остаются локальными, поэтому резервный экспорт нужен для переноса между устройствами.
