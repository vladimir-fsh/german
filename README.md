# Deutsch B1 Trainer

Персональный тренажер немецкого для русскоязычного ученика A2-B1. Работает локально без AI; OpenAI добавляет новые варианты занятий и обратную связь.

## Учебный цикл

1. Начальная проверка грамматики, чтения и письменная попытка.
2. Следующая задача выбирается по ошибкам, результатам и предпосылкам девяти навыков.
3. Самостоятельный ответ, проверка и исправление. Подсказки и первая попытка учитываются отдельно.
4. Повторение слов и новая ситуация на тот же навык спустя время.
5. Каждое пятое занятие - контрольная практика с учебным таймером.

В настройках выбираются Goethe B1 или telc B1, сложность A2/B1 и интересующие темы для AI-вариантов. Встроенные задания связаны с навыками и доступны без ключа. Это частичная экзаменационная подготовка; приложение не выдает сертификат уровня и не проводит полный пробный экзамен.

Умение считается подтвержденным спустя время после двух успешных первых попыток без подсказок на разных заданиях, с промежутком хотя бы три дня, после последней ошибки. Через 30 дней нужна новая проверка. Для письма сохраняется отдельная рубрика из пяти критериев; короткий текст не получает принудительную оценку A2/B1.

Слова из AI-занятий попадают в общий словарь. Карточки требуют ответа перед показом образца, чередуют воспроизведение и распознавание. Новая нагрузка ограничена пятью словами в день. Ошибка возвращается через минуту, первый успех - через десять минут, второй - через день; последующие интервалы растут до 90 дней. Это политика тренажера, а не универсальная норма.

Диалог сохраняет текст, историю и уточняющие вопросы. AI оценивает содержание, лексику и грамматику транскрипта. Аудирование и запись аудио не добавлены. Прежний браузерный голосовой ввод сохранен как необязательная функция; произношение, темп и паузы не оцениваются.

## Данные

Прогресс хранится в LocalStorage этого браузера. Формат v2 автоматически мигрирует прежний v1 с сохранением результатов и AI-лексики. Ответы и проверки занятий, версии письма и текст диалога сохраняются автоматически. Отдельные занятия считаются отдельно от учебных дней.

Импорт проверяет структуру, даты, значения и связи до замены данных. Поврежденное хранилище не перезаписывается автоматически. При ошибке сохранения работа остается в памяти; можно повторить сохранение или скачать JSON. В настройках доступны экспорт текущего прогресса и исходного содержимого хранилища. Синхронизации между устройствами нет; перенос выполняется через JSON.

Полный контент завершенных занятий хранится для последних 60 уроков; активные занятия и незавершенные черновики защищены от очистки. История попыток и словарь сохраняются отдельно.

## Запуск

Технологии: Next.js App Router, React, TypeScript, Tailwind CSS, OpenAI SDK. Отдельный backend не нужен.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Откройте `http://localhost:3000`. Для локальной практики ключ не нужен. Для AI укажите `OPENAI_API_KEY`; модель задается через `OPENAI_MODEL`, по умолчанию `gpt-5-mini`.

```bash
npm run build
npm start
```

В production AI требует `APP_ACCESS_PASSWORD`. Если пароль задан, все приложение защищено HTTP Basic; имя по умолчанию `trainer`, другое задается через `APP_ACCESS_USERNAME`. Для публикации используйте HTTPS. Секреты остаются на сервере. Тексты, переданные на AI-проверку, отправляются в OpenAI.

API ограничивает запрос 50 КБ, две одновременные обработки и 60 запросов в час на процесс. При нескольких экземплярах сервера нужен общий лимитер. Ошибки конфигурации и провайдера возвращаются в JSON; черновики сохраняются.

## Разделы

- `/`: учебные дни, выполненные занятия, серия и наблюдаемые умения.
- `/lesson`: начальная проверка, упражнения, чтение, письмо и контрольная практика.
- `/skills`: карта навыков, черновики и история попыток.
- `/vocabulary`: единый словарь с формами и конструкциями.
- `/review`: повторение слов и практика ошибок.
- `/speaking`: текстовый диалог и обратная связь.
- `/exam`: различия выбранного экзамена и ссылки на официальные материалы.
- `/settings`: учебная цель, темы, экспорт, импорт и восстановление.
