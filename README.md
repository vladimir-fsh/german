# Deutsch A2 - B1

Мобильный грамматический курс для русскоговорящего ученика. HTML, CSS и обычные JavaScript-скрипты, без сборки и npm-зависимостей. Сейчас написаны уроки 18-21: 18 учебных дней, словарь из 100 слов. Процент выполнения относится к доступным заданиям, а не к уровню B1.

В карточках приоритет у естественных повседневных вариантов: например, `genug`, `schaffen`, `besprechen`. Более формальные варианты показаны в примечании на обороте, с уточнением смысла при необходимости. Группы словаря - приблизительная учебная очередь, а не измеренная частотность. Старые ключи карточек сохраняют расписание и незавершённые сессии после смены основного варианта.

## Запуск

```sh
/usr/bin/python3 tools/serve.py 8778 --host 0.0.0.0
```

Откройте `http://<локальный-IP-Mac>:8778`, проверьте на ширине 390-420 px. Прогресс сохраняется на устройстве, в localStorage браузера.

Для телефона в той же Wi-Fi сети на этом Mac: `/usr/bin/python3 tools/serve.py 8778 --host 0.0.0.0`, затем откройте `http://<локальный-IP-Mac>:8778`. Mac должен оставаться включённым. Локальный адрес и опубликованный сайт хранят прогресс отдельно.

## Чат с объяснениями

Иконка чата справа внизу открывает объяснение текущего слова, задания или блока теории. Кнопки «Объясни проще» и «Разбери на части» отправляют готовый запрос. Для разбора конкретного слова можно сначала вписать его в поле. Внутри одного экрана можно задавать уточнения; при переходе к другому слову или заданию переписка очищается.

Чат появляется снизу компактной полупрозрачной панелью поверх открытой страницы.
Поле сразу получает фокус для клавиатуры iPhone, быстрые команды находятся над ним.
Переписка растёт вверх и прокручивается внутри панели. При системном уменьшении
движения анимация открытия отключается. Пока ключ не добавлен, вместо двух команд
показывается такая же кнопка «Добавить API-ключ». Нажатие на всю кнопку открывает ввод.
После подтверждения сохранения она заменяется двумя командами. Заголовка чата нет.

Чат обращается к серверной функции Firebase через существующий Google-вход. Через кнопку «Добавить API-ключ» в чате можно один раз ввести ключ и нажать «Сохранить в Firebase». Ключ записывается в Secret Manager проекта Firebase; после сохранения поле очищается, настройки закрываются и появляются команды объяснения. На других устройствах того же владельца ключ работает без повторного ввода, обратно в браузер возвращается только статус сохранения. Отдельного пункта настройки чата в «Ещё» нет. Модель `gpt-5-mini` и системный промпт задаются сервером. Серверная часть ещё требует первоначального развёртывания по [инструкции Firebase](firebase/README.md).

Переписка живёт только в памяти вкладки, до перезагрузки или закрытия, и очищается при смене аккаунта. Она не синхронизируется и не входит в резервные копии. В Firestore сохраняются счётчики лимитов и номер активной версии ключа без его значения. Доступ разрешён одному UID, ограничения чата - 5 запросов в минуту и 60 в сутки по UTC. Сохранение ключа ограничено отдельно: 2 раза в минуту и 10 в сутки. API OpenAI и сервер Firebase оплачиваются отдельно. Обработка секретов соответствует [рекомендациям OpenAI](https://developers.openai.com/api/reference/overview#authentication).

Контекст берётся из данных приложения, теория очищается от разметки. Скриншоты не используются. До проверки задания не отправляются ответы и `why`; обращение к чату до ответа отмечается как подсказка. Обработка ответа соответствует [Responses API](https://developers.openai.com/api/docs/guides/text).

## GitHub Pages

Публикация настроена в `.github/workflows/pages.yml`: каждый push в `main` проверяет приложение и автоматически публикует его на GitHub Pages. В сайт входят только `index.html`, иконка и каталоги `css`, `js`, `data`.

Каждая сборка получает версию `v<номер запуска>.<попытка>`, например `v8.1`, автоматически через `tools/stamp-pages.py`. Она показана в «Ещё → Настройки». Нумерация использует [переменные GitHub Actions](https://docs.github.com/en/actions/reference/workflows-and-actions/variables); повторная сборка тоже получает новую метку. Адреса JS/CSS содержат эту версию для обновления кэша. При локальном запуске показывается «Локальная версия».

Рабочий адрес: https://vladimir-fsh.github.io/german/. Прогресс сохраняется в браузере пользователя. Для переноса из локальной версии или с другого устройства импортируйте резервную копию через «Ещё» либо подключите синхронизацию с Firebase через Google-вход. API-ключ в перенос не входит.

В «Ещё» есть кнопки «Проверить обновления» и «Перезагрузить приложение».
Новая версия проверяется также при запуске и возвращении в приложение; на вкладке
«Ещё» появляется отметка. Перезагрузка выполняется только по нажатию, с обходом
кэша HTML. При ошибке сохранения она блокируется и предлагает сохранить или экспортировать данные.
Версии до добавления этой проверки нужно один раз открыть по ссылке с новым
query-параметром, например `https://vladimir-fsh.github.io/german/?update=check`.

## Проверки

Node.js 18 или новее, без установки пакетов:

```sh
node --test tools/test-regressions.js
node --test tools/test-swipe-back.js
node --test tools/test-updates.js
node --test tools/test-tutor.js
node --test tools/test-tutor-session.js
node --test tools/test-vocab-training.js tools/test-vocab-gestures.js
node --test tools/test-exercise-attempt.js
node --test tools/test-tutor-server.js
node --test tools/test-tutor-settings.js
node tools/test-sync.js
node tools/test-lessons.js
```

Параметры повторения находятся в `js/srs-config.js`. Изменения прогресса проходят через `Store.mutate`; текущее состояние имеет схему 7 и переносит старые схемы 2-6. Текущую версию Pages определяет коммит успешного запуска GitHub Actions. Общие правила разработки находятся в [AGENTS.md](AGENTS.md).

Жизненный цикл карточек находится в `js/vocab-training.js`, беседы - в
`js/tutor-session.js`, попытки задания - в `js/exercise-attempt.js`. Эти модули
проверяются через их интерфейсы. Экраны отвечают за DOM, размещение и жесты;
`Store`, `Practice` и `Sessions` сохраняют свои форматы данных. Термины практики
описаны в [GLOSSARY.md](GLOSSARY.md).

## Сохранение

Если платформа запрещает скачивание, нажмите «Показать прогресс текстом», затем «Копировать весь текст». При недоступном буфере обмена текст выделяется для ручного копирования через меню телефона. Сохраните JSON в заметках и вставьте в поле импорта в другой версии приложения. Экспортировать нужно именно из той версии, где сохранён прогресс: у каждого адреса своё хранилище браузера.

«Ещё» позволяет скачать резервную копию прогресса, черновиков учебных дней и сессий слов и ошибок, проверить и импортировать JSON, сохранить исходные записи поврежденного хранилища и повторить запись после ошибки квоты. Обычный импорт заменяет прогресс и проверяет структуру до изменения данных.

Черновики дней сохраняют текущий ввод, первые ответы, решенные пары и использование теории. История содержит последние 100 завершенных попыток. Незавершенные сессии карточек и ошибок сохраняют ввод и возобновляются после перезагрузки. Резервная копия переносит их на другое устройство. Одновременные ответы вкладок записываются в отдельные журналы. На карточках нет панели кнопок: нажатие показывает перевод, свайпы дают оценку. При предупреждении о квоте работа остается в памяти: экспортируйте ее до закрытия страницы.
