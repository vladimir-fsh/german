# Deutsch A2 - B1

Мобильный грамматический курс для русскоговорящего ученика. HTML, CSS и обычные JavaScript-скрипты, без сборки и npm-зависимостей. Сейчас написаны уроки 18-21: 18 учебных дней, словарь из 100 слов. Процент выполнения относится к доступным заданиям, а не к уровню B1.

В карточках приоритет у естественных повседневных вариантов: например, `genug`, `schaffen`, `besprechen`. Более формальные варианты показаны в примечании на обороте, с уточнением смысла при необходимости. Группы словаря - приблизительная учебная очередь, а не измеренная частотность. Старые ключи карточек сохраняют расписание и незавершённые сессии после смены основного варианта.

## Запуск

```sh
python3 tools/serve.py 8777
```

Откройте `http://127.0.0.1:8777`, проверьте на ширине 390-420 px. Облачная синхронизация подключается в среде артефакта через `claude.use("db")`; на локальном сервере прогресс сохраняется на устройстве.

Для телефона в той же Wi-Fi сети: `python3 tools/serve.py 8778 --host 0.0.0.0`, затем откройте `http://<локальный-IP-Mac>:8778`. Mac должен оставаться включённым. Локальный адрес и опубликованный сайт хранят прогресс и ключ отдельно.

## GitHub Pages

Публикация подготовлена в `.github/workflows/pages.yml`: после включения Pages с источником GitHub Actions каждый push в `main` проверяет приложение и публикует его. В сайт входят только `index.html`, иконка и каталоги `css`, `js`, `data`.

Ожидаемый адрес после включения: https://vladimir-fsh.github.io/german/. Для приватного репозитория нужен тариф GitHub с поддержкой Pages; на бесплатном тарифе репозиторий должен быть публичным. Прогресс и API-ключ сохраняются в браузере пользователя. Для переноса из Claude или локальной версии импортируйте резервную копию через «Ещё». На GitHub Pages нет облачной синхронизации Claude.

## Проверки

Node.js 18 или новее, без установки пакетов:

```sh
node --test tools/test-regressions.js
node --test tools/test-openai.js
node --test tools/test-swipe-back.js
node tools/test-sync.js
node tools/test-lessons.js
```

Параметры повторения находятся в `js/srs-config.js`. Изменения прогресса проходят через `Store.mutate`; текущее состояние имеет схему 6 и переносит старые схемы 2-5. При публикации обновляйте все устройства совместно. Номер артефакта меняется только при реальной публикации через `tools/stamp.sh`.

## Подключение OpenAI

В «Ещё → Подключение OpenAI» можно сохранить личный API-ключ и выбрать модель из списка. Поле вопросов убрано: интерфейс пока только сохраняет подключение и не отправляет запросы. По умолчанию выбрана GPT-6.1 Sol; также доступны GPT-6 Astra, GPT-6 Luna, GPT-4.1 и GPT-4.1 mini. Модели сверены с [OpenAI Docs](https://developers.openai.com/api/docs/models) 7 октября 2026 года. Доступ зависит от аккаунта пользователя.

Ключ хранится без шифрования в localStorage текущего браузера, отдельно от прогресса; он не входит ни в резервную копию, ни в экспорт исходного хранилища. Это личный браузерный режим с ключом пользователя, доступным скриптам сайта; для приложения с общим ключом нужен сервер. API оплачивается отдельно. Транспорт для будущих функций подготовлен через Responses API с `store: false`, но сейчас не вызывается из интерфейса. Проверки используют подставной API без настоящего ключа.

## Сохранение

Если платформа запрещает скачивание, нажмите «Показать прогресс текстом», затем «Копировать весь текст». При недоступном буфере обмена текст выделяется для ручного копирования через меню телефона. Сохраните JSON в заметках и вставьте в поле импорта в другой версии приложения. Экспортировать нужно именно из той версии, где сохранён прогресс: локальная страница не читает хранилище артефакта Claude.

«Ещё» позволяет скачать резервную копию прогресса, черновиков учебных дней и сессий слов и ошибок, проверить и импортировать JSON, сохранить исходные записи поврежденного хранилища и повторить запись после ошибки квоты. Обычный импорт заменяет прогресс и проверяет структуру до изменения данных.

Черновики дней сохраняют текущий ввод, первые ответы, решенные пары и использование теории. История содержит последние 100 завершенных попыток. Незавершенные сессии карточек и ошибок сохраняют ввод и возобновляются после перезагрузки. Резервная копия переносит их на другое устройство. Одновременные ответы вкладок записываются в отдельные журналы. На карточках нет панели кнопок: нажатие показывает перевод, свайпы дают оценку. При предупреждении о квоте работа остается в памяти: экспортируйте ее до закрытия страницы.
